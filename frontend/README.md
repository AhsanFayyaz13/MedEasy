# MedEasy — Frontend

React 19 + Vite SPA. See the root [README](../README.md) for setup, environment variables, the design
system and project structure.

```bash
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
npm run lint       # ESLint
npm run lint:css   # Stylelint (no raw colours outside src/styles/tokens.css)
```
