# MedEasy — frontend

React 19 single-page app built with Vite. Setup, scripts and environment variables are in the
[root README](../README.md); structure and design tokens in [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).

```bash
npm run dev        # http://localhost:5173 (expects the API; or run `npm run dev:memory` from the root)
npm run build      # production build in dist/
npm run lint       # ESLint
npm run lint:css   # Stylelint (raw colours only allowed in src/styles/tokens.css)
```
